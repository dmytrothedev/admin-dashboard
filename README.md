
# Admin Dashboard

An admin dashboard built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard) — Intermediate HTML & CSS course.

## About

This project focuses on practicing CSS Grid by building a complete admin dashboard interface.

The dashboard includes a sidebar, header, project cards, announcements, and trending sections.

The original design was customized with an **fsociety-inspired theme** based on the TV series *Mr. Robot*, featuring dark backgrounds, terminal-green accents, and monospace typography.

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox

## Features

- Dashboard layout built with CSS Grid
- Nested Grid and Flexbox layouts
- Sidebar navigation with hover effects
- Header with search bar, user profile, and action buttons
- Six project cards with action icons
- Announcements and trending sections
- Dark terminal-inspired interface

## What I Learned

- Building complex page layouts with CSS Grid
- Combining Grid and Flexbox for element positioning
- Working with nested grid containers
- Managing spacing, alignment, and sizing
- Applying CSS selectors and pseudo-classes
- Organizing CSS into logical sections
