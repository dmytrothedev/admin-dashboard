# Admin Dashboard

A dashboard layout project built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-admin-dashboard) — Intermediate HTML & CSS course.

## About

The goal of this project is to practice CSS Grid by building a complete admin dashboard interface.

The layout will include a sidebar, header, and main content area with project cards, announcements, and trending sections.

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox (where appropriate)

## Project Goals

- Build a structured dashboard using CSS Grid.
- Practice nested grid layouts.
- Improve element positioning, spacing, and alignment.
- Apply previously learned HTML and CSS concepts.
- Create a clean and organized user interface.
